## Introduction

CWE Navigation is an interactive browser for the [CWE Research Concepts view (CWE-1000)](https://cwe.mitre.org/data/definitions/1000.html). It presents the CWE hierarchy and related-weakness links as a searchable graph, making it easier to explore how software weaknesses are organized and connected.

## Data source and license

CWE data comes from the [MITRE CWE project](https://cwe.mitre.org/data/downloads.html). The application source is available under the [MIT License](LICENSE).
